# Task API

This is a simple Task Management API built with **ASP.NET Core Web API**.  
It allows you to create, read, update, and delete tasks.

## 🚀 Technologies
- ASP.NET Core 7.0
- Entity Framework Core
- SQL Server (LocalDB)
- Swagger for API documentation
